Frequently asked questions

What is Base64 used for?

Base64 turns arbitrary binary or text data into a safe set of ASCII characters, commonly used for embedding data in JSON, URLs, emails, or data: URIs.

Does this handle non-ASCII characters like emoji or Korean text?

Yes. The text is encoded as UTF-8 first, so emoji, Korean, Japanese, Chinese, and other non-ASCII characters round-trip correctly.

Is my text uploaded anywhere?

No. All encoding and decoding happens locally in your browser using standard Web APIs — nothing is sent to a server.
