Frequently asked questions

What is a UUID v4?

A UUID (Universally Unique Identifier) version 4 is a 128-bit identifier generated using random numbers. The chance of two UUID v4 values colliding is astronomically small, making them safe to use as unique IDs without central coordination.

What is a ULID and how is it different from a UUID?

A ULID (Universally Unique Lexicographically Sortable Identifier) encodes a timestamp in its first part, so ULIDs generated later always sort after earlier ones — useful as database keys. A UUID v4 is fully random and has no inherent ordering.

Are these generated using a cryptographically secure random source?

Yes. This tool uses the browser's crypto.getRandomValues() API, the same cryptographically secure random number generator used for security-sensitive operations.
