FAQ

Frequently asked questions

How do I copy a request as curl from my browser?

Open your browser's developer tools (F12), go to the Network tab, make the request, then right-click it and choose "Copy" > "Copy as cURL". Paste the result into this tool.

Which curl options are supported?

This tool understands the options browsers actually generate: the URL, -X/--request, -H/--header, -d/--data and its variants, -F/--form for multipart uploads, -b/--cookie, -u/--user for basic auth, -G/--get, -A/--user-agent, and multi-line commands with backslash continuations.

Is my curl command sent to a server?

No. Parsing and code generation both happen locally in your browser with JavaScript — nothing is uploaded anywhere. This matters since curl commands often contain auth tokens or cookies.
