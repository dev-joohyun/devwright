FAQ

Frequently asked questions

Does this verify the JWT signature?

No. This tool only decodes the header and payload segments — it does not verify the signature, since that requires the secret key or public key used to sign the token.

Is it safe to paste a real token here?

Decoding happens entirely in your browser and the token is never sent anywhere, but you should still avoid pasting real production tokens into any website as a general security practice.

What is a JWT?

A JSON Web Token (JWT) is a compact, URL-safe way to represent claims (like a user ID or expiry time) between two parties, made of a Base64URL-encoded header, payload, and signature separated by dots.
